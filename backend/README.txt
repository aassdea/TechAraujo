BACKEND TECHARAUJO - MYSQL/MARIADB

1) En XAMPP inicia Apache y MySQL.
2) Importa backend/techaraujo_corregido.sql desde phpMyAdmin.
3) Copia la carpeta techaraujo a C:/xampp/htdocs/.
4) La API queda en http://localhost/techaraujo/backend/api.php
5) Si MySQL usa otra contraseña, edita backend/api.php o define TECH_DB_PASS.
